# Контент TÖMER — банк экзаменационных материалов

Гибридная модель (решение основателя 09.07.2026, вариант C):

1. **Сейчас** — оригинальный контент в формате TÖMER (`source: "original"`).
   Формат экзамена не охраняется авторским правом; сами тексты и вопросы — наши,
   с нуля. Прошлые реальные варианты НЕ копируем никогда (DESIGN-CONTENT-TOMER §3).
2. **Слот под официальные материалы** — когда появится партнёрство:
   `source: "official-<партнёр>"` + поле `license`. Код не различает источники —
   раннер читает единую схему, пометка источника показывается в UI мелким текстом.

## Схема файла (единая для original и official)

```jsonc
{
  "id": "okuma-b2-001",
  "source": "original",            // "original" | "official-<slug>"
  "license": null,                 // для official: строка условий использования
  "skill": "okuma",                // okuma | dinleme | yazma | konusma
  "level": "B2",
  "title": "...",
  "body": "...",                   // okuma: текст; dinleme: скрипт (AHU:/FATİH: — голоса TTS)
  "audioSrc": null,                // dinleme: /audio/tomer/<id>.mp3 (генерится скриптом)
  "questions": [
    {
      "id": "q1",
      "type": "detail",            // detail | inference | main_idea | vocab_in_context | not_true
      "prompt": "...",             // турецкий
      "options": ["...", "...", "...", "..."],
      "answer": 0,                 // индекс ДО перемешивания (раннер перемешивает сам)
      "rationale": "..."           // для ревьюера: почему верен ответ и чем правдоподобны дистракторы
    }
  ],
  "meta": {
    "author": "ai-draft",          // ai-draft → после ревью: имя нейтива
    "reviewedBy": null,
    "createdAt": "2026-07-09"
  }
}
```

Правила качества (чек-лист ревью — DESIGN-CONTENT-TOMER §4):
- Тип вопросов в секции разнообразен (минимум 3 типа из 5 на текст).
- Дистракторы правдоподобны: каждый «почти верен» и опровергается конкретным
  местом текста (см. rationale).
- Ответ НЕ находится дословным совпадением слов вопроса и текста.
- Уровень лексики/грамматики соответствует заявленному CEFR.
- Ничего не заимствовано из реальных вариантов TÖMER.

## Процесс

AI-драфт → нейтив-ревью по чек-листу (правки в файле, `reviewedBy`) →
для dinleme: TTS-аудио скриптом (по образцу `scripts/generate-diagnostic-audio.mts`) →
подключение в мок-раннер. Масштаб — только после утверждения образцов основателем.

Образцы идеального качества: `samples/okuma-b2-sample.json`, `samples/dinleme-b2-sample.json`.
